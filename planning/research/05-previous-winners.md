## Patterns (INFERRED, low–medium confidence)
1. **NEAR's thematic arc is consistent:** user-owned AI + chain abstraction (2024) → agents + intents + private AI + programmable money (2026). Projects that use NEAR-specific primitives fit the organizer narrative better than generic dApps.
2. **Measurability has been asked for before** (Useful Agents required benchmarks). This event's AI screener and the thesis track's "reproducible evidence" continue that preference.
3. **Ecosystem partner tracks were bountied separately before** (NOVA, HOT, PingPay). This edition has no partner bounties — all value is in the 13 equal tracks + grand prize.
4. **Community voting** existed in the Jan 2026 Sandbox (NEAR Legion). This edition has no vote, but the X demo post with @NearLegion / @NearBuilders tags gives community amplification (S2).

## Overused approaches in NEAR hackathon history (INFERRED)
Generic freelancing/job boards, marketplace clones, donation/crowdfunding dApps, and "AI chatbot + wallet" projects recur across NEAR hackathon repo listings (e.g. GitHub `near-api-js` topic shows multiple job/freelance platforms from 2022). Treat these shapes as low-originality defaults.
